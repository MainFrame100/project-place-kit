# Единое место по проектам

Одна папка на аккаунт, внутри — по папке на проект. В каждой: сырьё (выгрузки чатов, письма, файлы), журнал событий по дням и три документа — паспорт, статус, карта материалов. Каждый факт со ссылкой на источник. Нейронка собирает, человек проверяет.

## Как начать — три фразы

1. Склонируйте репозиторий: `git clone https://github.com/MainFrame100/project-place-kit <папка>` — или скажите Claude Code / Codex: «склонируй … в папку <папка>».
2. Откройте в папке Claude Code или Codex и скажите: **«Настрой по SETUP.md»**. Нейронка поставит окружение, попросит два ключа с my.telegram.org и покажет QR для входа в Telegram.
3. Скажите: **«Заведи проект <название> и выгрузи чат <название чата>»** — выгрузится две недели; нужно больше — скажите «за 60 дней».

Дальше — словами:

- «По скиллу project-status разложи сырьё проекта <название> в журнал»
- «Собери паспорт, статус и карту материалов»
- «Что сейчас по проекту?» · «Где лежит …?» · «Какие решения приняты?»
- «Проверь статус: сначала проверяльщиком по источникам, потом скептиком. Покажи натяжки»
- «Поправка: … — запиши как факт с моих слов»
- «Проверь документ по скиллу quality-check»
- «Выложи всё в закрытый репозиторий на GitHub» — сначала проверка на пароли и порядок, потом публикация, потом проверка, что репозиторий закрыт

## Что внутри

```
CLAUDE.md / AGENTS.md   правила — нейронка читает при каждом запуске
SETUP.md                установка: окружение, Telegram, скиллы, свой репозиторий, ночное обновление
projects/               по папке на проект; _template — шаблон
automation/             скрипты; tg_export.py — выгрузка Telegram (личка, группы, каналы, темы)
.claude/skills/         project-status — сырьё → журнал → документы → проверка;
                        github — проверка → исправление → публикация;
                        quality-check — подтягивается при установке
.env.example            какие ключи нужны; сами ключи — только в .env
```

Ключи и сессия Telegram в репозиторий не попадают — `.gitignore` и правило в `CLAUDE.md`. Пароли из переписки скрываются при выгрузке (`automation/redact.py`, по-русски и по-английски), перед коммитом — `python automation/publish_check.py` (в нём и проверка на пароли).

## Что не так

- Код входа не пришёл — он приходит в сам Telegram, не по SMS. Выключите VPN на телефоне.
- Нет Python или git — скажите нейронке «поставь». Windows — работайте в WSL или Git Bash.
- Чат не находится — «покажи список чатов», возьмите точное название.
