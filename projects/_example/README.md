# Вектор — учебный пример

- Вымышленный проект для открытого репозитория: клиент, имена и цифры выдуманы, реальных клиентов агентства не описывает.
- Показывает конвейер: сырьё → журнал → паспорт, статус, карта материалов.
- Клиент — «Вектор»: сайт vektor-filter.example, CRM `crm.vektor-filter.example`; отрасль и юрлицо в сырье не названы — [GAP].
- Что в работе: доставка писем по заявкам после переезда CRM, отчёт за август, план по английской версии сайта, нецелевой трафик в рекламной сети.
- Период сырья — 2026-09-01 — 2026-09-07, 35 сообщений, выгружено 2026-09-08.

Где что лежит:

- [sources/telegram-vektor-proekt.md](sources/telegram-vektor-proekt.md) — сырьё, выгрузка рабочего чата. Не правится.
- [journal/2026-09.md](journal/2026-09.md) — события по дням, файл на месяц. Только дописывается.
- [passport.md](passport.md) — клиент, направления работы, деньги и сроки, команда, где общаемся.
- [status.md](status.md) — ситуация на сегодня, обязательства, блокеры, открытые вопросы, [GAP]-лист. Пересобирается целиком.
- [materials.md](materials.md) — ключевые ссылки: сайт, CRM, где лежат отчёты.
- Правила фактов и оформления — [CLAUDE.md](../../CLAUDE.md), порядок работы — [скилл project-status](../../.claude/skills/project-status/SKILL.md).
