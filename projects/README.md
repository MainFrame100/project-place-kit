# projects — по папке на проект

Завести: `cp -r projects/_template projects/<имя>` и заполнить `README.md` проекта. Как выглядит собранный проект — `projects/_example/` (вымышленная компания «Вектор», учебный образец: сырьё, журнал, три документа). Папки на `_` — не проекты, данных клиентов в них нет.

| Файл | Что | Как живёт |
|---|---|---|
| `README.md` | о проекте и где что лежит | правится при изменении структуры |
| `sources/` | сырьё: выгрузки чатов, письма, документы | только пополняется, не правится |
| `journal/YYYY-MM.md` | события по дням, каждое со ссылкой на сырьё; много событий — файл на неделю или день (`journal/README.md`) | только дописывается |
| `passport.md` | клиент, продукт, команда, договорённости | правится редко |
| `status.md` | что сейчас: ситуация, обязательства, блокеры, вопросы, `[GAP]`-лист | пересобирается из журнала |
| `materials.md` | где что лежит: ссылка, что это, откуда известно (#сообщение), дата | пересобирается |

Паспорт, статус и карта — три среза одних данных. Данные живут в журнале и сырье, документы из них собираются — скилл `project-status`.

Обновление: только новое с даты «Обновлено» в статусе. Журнал дописать, статус пересобрать.
