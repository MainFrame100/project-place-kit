# journal — события по дням

Файл на месяц: `YYYY-MM.md`. Только дописывается.

Событий много — файл дробится: больше ~200 записей в месяц или больше ~800 строк — файл на неделю `YYYY-Www.md` (`2026-W37.md`); при ежедневном обновлении и плотном потоке — файл на день `YYYY-MM-DD.md`. Дневная запись остаётся той же, меняется только имя файла. Шаг один на проект, записан в `README.md` проекта; менять — с начала следующего периода, старые файлы не переименовывать.

Запись — те же поля, что в правиле фактов `CLAUDE.md`, столбиком:

```
## 2026-09-03 — коротко, что произошло
- Источник: [telegram-<чат>.md #24877](../sources/telegram-<чат>.md) — ссылка на файл + номер сообщения (или письмо, файл)
- Кто → кому: Анна → Дмитрий
- Тип: решение / обещание / результат / вопрос без ответа / конфликт
- Что: дословно или близко к тексту, с «цитатой»
```

Правка человека — такая же запись: «со слов <кто>, <дата>». Старое не удаляется.
